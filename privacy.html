Privacy Policy & Transparency

Effective Date: October 16, 2026 • TravelEase Portfolio Project

Portfolio Demonstration Notice: TravelEase is a fictional brand created exclusively for frontend software development portfolio evaluation. This privacy statement describes client-side data handling principles for demonstration purposes.

1. Overview & Portfolio Purpose

TravelEase ("we", "our", or "the application") is a static frontend website developed to showcase clean HTML5 semantics, modern responsive CSS3 techniques, and robust vanilla JavaScript ES6+ algorithms. We respect the privacy of every visitor and recruiter reviewing this website.

Because this application operates purely in the client browser without a dedicated backend server or remote database, we do not collect, transmit, sell, or commercialize any personally identifiable information (PII).

2. Information Handled During Demonstration

When you interact with the interactive demo forms on this website (such as the booking simulation form, the newsletter subscription bar, or the contact feedback form):

  • Client-Side Validation Only: All form inputs (names, email addresses, phone numbers, travel dates) are evaluated exclusively inside your local browser's memory using JavaScript regular expressions and validation constraints.
  • No Remote Transmission: Form submissions trigger simulated on-screen feedback modals and toasts. None of the values you type are sent over HTTP/HTTPS to an external database or CRM.
  • Transient Memory: Refreshing or closing your browser tab immediately discards all submitted form states.

3. Cookies & Local Browser Storage

TravelEase does not set tracking cookies, behavioral tracking pixels, or third-party marketing identifiers. If you navigate through the website, standard browser URL parameters (e.g. ?category=Adventure or ?package=santorini-sunset-dream) are used solely to preserve state between views.

4. Third-Party Content Delivery Networks (CDNs)

To guarantee optimal performance, accessibility, and high visual fidelity, TravelEase loads static resources from reputable public Content Delivery Networks:

  • Bootstrap 5 & Bootstrap Icons: Loaded from jsDelivr CDN (cdn.jsdelivr.net).
  • Google Fonts: Typography loaded securely from Google Fonts (fonts.googleapis.com).
  • Destination Photography: Curated high-resolution illustrative travel imagery provided via Unsplash (images.unsplash.com).

These CDNs may process your IP address and standard HTTP request headers strictly to fulfill network content delivery in compliance with global security protocols.

5. Accessibility & Data Transparency Commitment

This project was built following the Web Content Accessibility Guidelines (WCAG 2.1 Level AA). All error notifications and state transitions are broadcast to assistive technologies via accessible landmarks and aria-live polite regions.
