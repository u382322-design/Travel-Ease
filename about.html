Frontend Engineering Portfolio

About This Web Application

This project was created to demonstrate high-standard modern frontend engineering capabilities for a professional CV. It illustrates clean architecture using standard web primitives:

  • Semantic HTML5: Accessible landmarks (header, nav, main, section, article, aside, footer), strict heading hierarchy, and ARIA attributes.
  • Responsive Styling: Modular CSS3 design tokens combined with Bootstrap 5 utility grid, custom travel theme, and graceful mobile typography.
  • Vanilla ES6+ JavaScript: Reactive catalogue filtering, dynamic search queries, duration and budget filters, and robust client-side form validation.
  • Ethical Transparency: Clear distinctions between portfolio demonstration simulations and real backend booking services.
